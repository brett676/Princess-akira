# Princess Oona and the Missing King

A 33-page choose-your-path pony adventure. King Giovanni has been kidnapped
by his brothers, Uncle Bayzen and Uncle Bastien (B and B), and Princess Oona
must rescue him. Every page is a moral or psychological dilemma. Wise
choices bring Oona 2 leagues closer to the King; unwise ones let B and B
carry him 1 league further away. A player choosing at random wins about
40% of the time.

This folder is its own Vercel project (princess-oona). In Vercel, import the
repo and set Root Directory to `princess-oona`. `vercel.json` pins the
settings: no framework, no build, output `public/`, and `/game` also serves
the game.
